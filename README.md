# Excel Sales Dashboard & Profitability Analysis

## Project Overview
This project presents an Excel-based Sales Dashboard designed to analyse revenue, profitability, sales trends, and geographical performance.
The dashboard provides a consolidated view of key performance indicators (KPIs) and interactive filters to support business decision-making.
## Objectives
- Analyse total revenue and gross profit.
- Evaluate monthly sales and profitability trends.
- Compare revenue across countries.
- Understand revenue distribution by sales channel.
- Explore performance using interactive filters.
## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- KPI Cards
- Interactive Slicers
- Data Visualisation
